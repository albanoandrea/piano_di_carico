# piano_di_carico
Aiuta a creare un piano di carico

## Privacy

I dati inseriti restano nel browser (`localStorage`). Il tool non li invia a nessun server e non usa Google Fonts. GitHub Pages e cdnjs (Cloudflare) vedono solo i dati tecnici della connessione, come l'IP.
